# 考试网上阅卷工作台改造
范围：仅旧服务。没有改独立 review 服务、数据库结构、Nginx 或答题卡版本。

答卷左栏；考试逐题参考答案及评分标准右栏；打分区和提交按钮固定。手机上下显示，标准和打分独立滚动。参考答案保留用户录入的完整文字，不做OCR，不猜测缺失标准。可查看答案原件，手动刷新考试答案。

评分成功后自动接下一份；保存失败留在原卷。只读预览预热下一份图片，实际领取仍通过原子接口，冲突409时回退自动领取。提交有同步锁，未加载图片不允许评分。批注响应防串卷，草稿写入合并，并在关闭面板时保存。先前未提交草稿仅恢复当前已领卷。

性能：分数按学生集合分批读取（每批500），领取仅读取单卷，题目列表按小ID去重、完整模板每个版本只读取一次。每题满分取扫描批次绑定的不可变PDF版本。

验证：全项目类型检查；读服务测试覆盖99份卷单次成绩查询、单卷读取、分配范围、只读预览和未识别客观题时的PDF满分。浏览器使用隔离样卷和模拟评分接口，未写入真实分数；覆盖1440/390宽度、作文分数、小数分、重复点击、领取冲突、保存失败、图片加载保护和参考答案缓存。模拟评分保存延迟150ms，提交到下一份显示275ms，仅用于功能验收，不等同用户公网速度。

构建复用原依赖和原生识别器；只替换旧服务镜像中的web/server产物。回滚可用发布前镜像，仅重启旧服务，不恢复数据库，不覆盖新增任务或评分。

大批量启动恢复：只结算尚未保存的自动识别结果；答案来源已回填时不再扫描审计归档；只为已生成主观任务且没有同算法阶段任务的卷补建客观队列。已有持久任务继续按原机制恢复，不重复遍历每卷每题。补丁通过类型检查、身份确认计分和部分就绪卷生成测试。
