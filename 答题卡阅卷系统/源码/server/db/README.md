# 数据库说明

## 职责

保存数据库连接、适配、建表结构与升级迁移。

## 文件导航

| 文件 | 职责 |
| --- | --- |
| [schema.sql](./schema.sql) | 本地数据库基础结构 |
| [schema.mariadb.sql](./schema.mariadb.sql) | 服务端数据库基础结构 |
| [mysql.ts](./mysql.ts) | 服务端数据库连接与初始化 |
| [index.ts](./index.ts) | 通用数据库初始化和访问 |
| [migrations.ts](./migrations.ts) | 本地结构升级 |

## 修改与验收

真实连接信息来自环境，禁止写入仓库。更新前备份数据库与关联文件；变更应先在隔离库验证幂等、失败回滚和现有分数保留。

具体构建和隔离回归命令见项目根目录“使用说明/开发与测试说明.md”。
