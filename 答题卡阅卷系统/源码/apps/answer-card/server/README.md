# 应用服务说明

## 职责

负责启动接口服务、接入业务路由，并提供模板、文档、识别和静态资源能力。

## 文件导航

| 文件 | 职责 |
| --- | --- |
| [index.ts](./index.ts) | 应用初始化、鉴权接入、业务路由和资源服务 |
| [recognition.ts](./recognition.ts) | 选择识别器并执行原生识别 |
| [pdf.ts](./pdf.ts) | 答题卡文档生成与分页相关处理 |
| [middleware.ts](./middleware.ts) | 考试访问范围和查看权限门禁 |
| [wenjuan.ts](./wenjuan.ts) | 问卷相关服务 |

## 修改与验收

模式与接口前缀由部署环境确定。调整代理、资源目录和识别器路径时，需检查普通入口、旧版入口和独立阅卷，不应只测试管理员账号。

具体构建和隔离回归命令见项目根目录“使用说明/开发与测试说明.md”。
