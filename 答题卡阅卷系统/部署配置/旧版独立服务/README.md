# 旧版独立服务说明

本目录保存旧版扫描件阅卷服务的部署辅助脚本与历史结构升级。它与受保护的独立阅卷入口可能使用不同的容器、接口前缀及数据库，不能直接互换配置。

## 文件导航

| 文件 | 用途 |
| --- | --- |
| `schema.sql` | 扫描件批次、原卷、模板与评分的补充结构 |
| `guard.py` | 保护状态和资源检查辅助 |
| `build.py` | 受保护条件下的构建辅助 |
| `runtime.py`、`switch.py` | 特定部署环境的启动和切换辅助 |
| `test-setup.cjs`、`test-flow.cjs` | 临时测试数据准备与流程回归 |
| [考试进度说明](./考试进度说明.md) | 扫描批次与考试进度实现记录 |
| [阅卷工作台说明](./阅卷工作台说明.md) | 专注阅卷工作台实现记录 |
| [流水号说明](./流水号说明.md) | 流水号与正式分数关联规则 |

## 使用前检查

这些脚本源自特定主机，可能包含原有的路径、端口、容器名和状态目录。目录中文化后，不能直接把旧命令复制到新部署中执行；应按当前目标环境核对每个绝对路径、接口前缀和卷挂载。

旧网页构建使用 `VITE_LEGACY_ONLY=1`，对应服务运行使用 `PROJECTX_LEGACY_ONLY=1`。数据库、原件和切图目录需保持隔离。主入口使用的媒体票据、教师权限、评分队列和受保护入口不能因旧服务更新而被替换。

## 数据与操作边界

原扫描件、完整数据库快照、账户口令、会话、识别报告、部署报告与人工复核清单保存在仓库之外。历史脚本引用的报告文件可能属于这些外部运行产物，不能因为仓库中没有报告就自行补造。

重新识别、修改身份、重新生成主观题、切换正反面、重新计分和发布均可能写入业务数据。先备份并在隔离环境验证，不在真实考试里运行测试脚本。

## 历史功能范围

旧版逐步加入了模板目录、扫描件滚动浏览、正常记录批量确认、异常筛选、答案配置、二维码辅助定位、正反面交换、客观题重算、主观题优先生成、稳定流水号与教师阅卷进度。历史版本和原部署细节可以从提交记录追踪；当前行为以源码及目标环境配置为准。

完整上线、备份与故障检查流程见[部署与维护说明](../../使用说明/部署与维护说明.md)。
