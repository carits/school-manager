# 界面设计说明

本目录保存界面设计规范、实施计划、演示和样式令牌。当前实际运行界面以源码构建结果为准，设计演示不能替代验收。

| 内容 | 位置 | 用途 |
| --- | --- | --- |
| [设计规范](./设计规范.md) | 原设计文档 | 主题、颜色、组件和页面视觉规范 |
| [实施计划](./实施计划.md) | 原实施文档 | 设计迁移的任务拆分与历史检查项 |
| 交互演示 | `demo/demo.html` | 静态演示和界面对照 |
| 样式令牌 | `tokens/tokens.css` | 颜色、间距和主题参考 |
| 历史基线 | `baseline/` | 已提交的界面基线说明或图片 |

## 阅卷界面重点

答卷区可读且不被评分栏遮挡；手机能滚动；评分、保存、上一份与下一份易于触达；参考标准可折叠；历史教师分与人工智能建议优先呈现；每次切换都核对流水号与图片一致。修改布局时同时检查桌面、窄屏和手机。

历史方案中的工具名和代码标识保留原样。涉及当前实现位置，见[系统结构与目录说明](../使用说明/系统结构与目录说明.md)。
