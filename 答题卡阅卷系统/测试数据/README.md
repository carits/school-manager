# 测试数据说明

本目录只用于隔离开发和回归，不保存真实学生答题卡或正式成绩。`demo-exams/` 包含演示考试的导入与校验脚本，内部脚本目录已改为“脚本”。

## 使用步骤

1. 准备空的隔离数据库和独立文件目录，检查环境变量不会连接生产库。
2. 启动服务完成建表，再查看演示种子脚本的输入和副作用。
3. 运行种子与验证工具；完成后清理测试库和临时文件。

```bash
npx tsx 测试数据/demo-exams/脚本/seed.ts
npx tsx 测试数据/demo-exams/脚本/verify.ts
```

演示账户规则由种子脚本决定，不用于生产账户配置。真实数据环境不得开启演示固定口令开关。导入脚本可写入数据，执行前必须核对目标环境。核心无真实数据回归见[开发与测试说明](../使用说明/开发与测试说明.md)。
