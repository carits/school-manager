# 人工智能参考分说明

## 参考分与正式分

人工智能建议包含建议分、理由、评分标准版本和输入信息。建议与教师正式分分开保存；上传或复核建议不会自动覆盖教师正式评分。界面显示的“采用”应先填写草稿，再由教师保存。

单题建议主要由 `源码/server/services/AiScoreSuggestionService.ts` 管理；合并题块由 `LegacyReviewGroupService.ts` 管理，并验证题号、成员和总分范围。批量采用仍需检查权限、题块范围及确认提示，不能绕过正式评分接口。

## 复核要求

1. 使用原卷可见内容与本次正式评分标准，不能根据旧分倒推答案。
2. 说明具体得分点和扣分点；字迹模糊、裁切不完整或身份争议应标记待复核。
3. 零分也需要对应原卷依据；空白和未加载成功不能混为一谈。
4. 合并题块分别说明各小题依据，再给出本组建议总分；历史教师小题分只作参考。

## 本批语文作文口径

本节记录本批用户提供的口径，不作为所有考试的默认标准。满分50分，建议最高48分；不跑题、叙事完整、字数超过500字，起评分38分。

| 类型 | 条件 | 调整 |
| --- | --- | --- |
| 加分 | 生动细节 | 加2分 |
| 加分 | 细腻真实感受 | 加2分 |
| 加分 | 思想独特深刻 | 加2分 |
| 加分 | 超过600字、超过700字 | 分别加2分、加3分；按所达到的一档计 |
| 加分 | 卷面整洁美观 | 加1至2分 |
| 扣分 | 标题未补充 | 扣2分 |
| 扣分 | 400至499字、300至399字 | 分别扣2分、扣4分 |
| 限分 | 低于300字 | 不超过20分 |
| 扣分 | 严重偏题、离题 | 扣5分 |
| 扣分 | 书写潦草 | 扣1至2分 |
| 限分 | 思想或价值观有严重问题 | 0至19分 |

没有严重问题的作文不低于30分。复核理由应写出字数判断、完整性、细节、感受和卷面依据；无法确认的部分交人工复核。
