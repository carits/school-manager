# 部署与维护说明

## 部署组成

本项目包含浏览器界面、接口服务、数据库和文件存储。扫描识别还需要文档分页工具与原生识别器；旧版独立服务的守护和部署辅助文件位于[部署配置](../部署配置/说明.md)。

## 环境设置

复制示例环境文件，再按实际环境填写；真实配置不提交仓库：

```bash
cp .env.example .env
docker compose -f compose.yml config
docker compose -f compose.yml up -d --build
```

| 配置 | 含义 |
| --- | --- |
| `PROJECTX_MARIADB_HOST`、`PROJECTX_MARIADB_PORT` | 数据库连接地址 |
| `PROJECTX_MARIADB_DATABASE`、`PROJECTX_MARIADB_USER`、`PROJECTX_MARIADB_PASSWORD` | 业务库及访问账户 |
| `MARIADB_ROOT_PASSWORD` | 容器数据库管理口令 |
| `PROJECTX_ADMIN_PASSWORD` | 管理员初始化相关配置，已有账户持久化逻辑以账户服务为准 |
| `ANSWER_CARD_DATA_DIR` | 原件、切图及服务数据目录 |
| `ANSWER_CARD_RECOGNIZER_EXE` | 原生识别器可执行文件 |
| `ANSWER_CARD_PORT` | 本机发布端口 |
| `PROJECTX_LEGACY_ONLY` | 选择旧版独立服务运行模式 |

## 原生识别器与代理

```bash
npm run native:build:linux
```

编译需要图像识别依赖和编译器，输出至 `运行资源/native/linux-x64/`。容器构建会复制识别器和数据库结构文件。生产代理参考 `部署配置/nginx-location.conf`，旧入口和独立阅卷的接口前缀必须与构建模式相符。

## 备份与更新

同时备份数据库、答题卡原件、切图、模板以及非仓库配置。只备份代码无法恢复阅卷结果。记录代码提交、镜像、环境变量版本和数据备份时间；旧版专用部署脚本可能包含特定主机路径，换环境前逐项核对。

线上教师正在阅卷时，先在隔离目录构建和验证，再选择维护窗口切换。数据库迁移先检查可回退性，不把镜像回退等同于数据库回退。健康检查至少确认登录、教师可见题块、图片读取和读取已评分数据。

## 故障检查顺序

1. 反向代理状态与静态资源地址。
2. 接口响应时间、服务日志与数据库连接。
3. 数据磁盘容量、识别队列和原生识别器依赖。
4. 题块权限、图片版本、分配范围和合并题配置。
