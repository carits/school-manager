# 系统结构与目录说明

## 主要链路

```text
扫描原件 → 模板定位与身份/选项识别 → 人工异常复核
          → 主观题切图 → 题块分配 → 教师评分 → 汇总与导出
                         人工智能参考分 ↗
```

## 源码结构

| 位置 | 职责 |
| --- | --- |
| `源码/apps/answer-card/client/` | 浏览器应用、工作模式与界面状态 |
| `源码/apps/answer-card/client/components/` | 考试、题块选择、单题阅卷、合并阅卷、分配、进度和导出组件 |
| `源码/apps/answer-card/client/pages/` | 自定义扫描件和答题卡设计页面 |
| `源码/apps/answer-card/server/` | 服务入口、模板、文档处理、识别与静态资源服务 |
| `源码/server/routes/` | 账户、阅卷、分配、合并题块、成绩与导出接口 |
| `源码/server/services/` | 导入、切图、识别、分配、评分、建议与汇总业务 |
| `源码/server/db/` | 数据库连接、建表、迁移与事务适配 |
| `源码/server/repositories/` | 数据读取与持久化封装 |
| `源码/shared/` | 类型、题卡模型、评分、排名和共享校验 |

## 关键文件

单题阅卷为 `GradePanel.tsx`，合并题块阅卷为 `ReviewGroupPanel.tsx`；教师进度为 `TeacherProgressPanel.tsx`，考试扫描进度为 `ExamPdfProgressPanel.tsx`。身份与导入位于 `LegacyPdfApp.tsx` 和对应服务中。

## 持久化与图片

任务、分配、正式分、建议和审计由数据库保存；原件与切图存放在服务数据目录，数据库保存关联。浏览器可以缓存相邻图片以加速翻卷，但图片缓存不能替代正式分数保存，也不保证浏览器退出后内存还存在。

## 命名边界

主目录及一级功能目录使用中文。源码内部目录、函数、接口路径、数据库表和外部工具要求的文件名保留既有技术标识，避免改变已有登录、资源链接和数据关联。此规则不要求将程序语言关键字或第三方库名称翻译成中文。
