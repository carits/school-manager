# 答题卡阅卷系统

本项目提供答题卡设计、扫描件识别、按题分配阅卷和成绩汇总。教师正式评分与人工智能参考分分别保存；是否采用参考分由教师决定。

## 快速开发

在本目录执行：

```bash
npm ci
npm run typecheck
npm run dev
```

开发界面端口为 `5173`，服务端默认为 `5174`；开发代理和生产反向代理的路径不同，访问方式以[开发与测试说明](./使用说明/开发与测试说明.md)为准。

## 入口与数据边界

- `/answer-card/`：答题卡应用入口。
- `/answer-card/custom-pdf/`：自定义扫描件导入与处理。
- `/answer-card/review/`：独立阅卷任务入口。
- `/wenjuan/`：独立问卷入口。

旧版独立服务使用专用接口前缀 `/answer-card/legacy-api/`。不同入口是否启用由构建参数、服务环境和反向代理共同决定；改目录名不会更改这些网址。仓库目录调整不等同于重新部署线上服务。
