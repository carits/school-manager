# 中雅实验管理系统

本仓库保存学校管理系统源码。按中文主目录选择项目；答题卡、学生名册、成绩数据库与账户凭据由部署环境保存，不放入代码仓库。

| 主目录 | 功能与说明 |
| --- | --- |
| [答题卡阅卷系统](./答题卡阅卷系统/README.md) | 答题卡设计、自定义扫描件导入、身份与客观题识别、教师阅卷、人工智能参考分、成绩汇总和导出 |
| [学籍管理系统](./学籍管理系统/README.md) | 学生资料与学籍业务，操作方式见该目录原有说明 |
| [延迟服务核对](./延迟服务核对/README.md) | 延迟服务申报和核对，操作方式见该目录原有说明 |

## 从哪里开始

- 教师阅卷：阅读[教师使用说明](./答题卡阅卷系统/使用说明/教师阅卷说明.md)。
- 管理员：阅读[管理员使用说明](./答题卡阅卷系统/使用说明/管理员操作说明.md)。
- 开发维护：阅读[系统结构与目录说明](./答题卡阅卷系统/使用说明/系统结构与目录说明.md)。
- 安装和上线：阅读[部署与维护说明](./答题卡阅卷系统/使用说明/部署与维护说明.md)。

## 命名约定

项目主目录、一级功能目录和新增说明标题使用中文。工具识别的 `README.md`、`package.json`、`Dockerfile` 等文件名，以及源码内部的导入标识符、接口地址、数据库字段保留其技术约定。所有说明正文使用中文；命令和代码示例按可执行格式书写。
